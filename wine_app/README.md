# Вино в подборку

Приложение для домашнего задания 3. Оно оценивает качество вина по 12 признакам. Хорошим считается вино с оценкой от 7 баллов.

## Запуск на компьютере

Проверено с Python 3.13.18. Используйте Python 3.13 и версии библиотек из requirements.txt.

Откройте терминал в папке wine_app:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

На Windows вместо source выполните `.venv\Scripts\activate`. После запуска откройте адрес из терминала, обычно http://localhost:8501.

## Файлы

В папке находятся app.py, model.joblib, config.json, test.csv, requirements.txt и README.md.

В model.joblib сохранён весь пайплайн StandardScaler и LogisticRegression. В config.json находится порог, выбранный на валидации по максимальному precision при recall не ниже 0.7. В test.csv сохранена тестовая выборка. Точные дубликаты удалены до окончательного разбиения
Во вкладках можно оценить одно вино, посмотреть метрики, загрузить CSV и посмотреть коэффициенты модели. Пример CSV скачивается прямо в приложении. Общий ползунок порога работает во всех вкладках.

## Кэширование

Модель загружается через st.cache_resource, чтобы один и тот же объект использовался между перезапусками страницы. Таблица и вероятности кэшируются через st.cache_data, который возвращает копии данных. Аргумент _model исключён из хеширования, а версия файла модели передаётся отдельно для обновления кэша при замене модели.

Порог не входит в аргументы функции test_proba, поэтому при его изменении вероятности на тесте не считаются заново. Если вызвать joblib.load без декоратора, модель будет читаться с диска при каждом действии пользователя.
